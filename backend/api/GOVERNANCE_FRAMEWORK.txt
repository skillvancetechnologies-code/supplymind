GOVERNANCE DEFINITION
════════════════════════════════════════

Supplier Monitoring:
  All 200 suppliers tracked continuously
  via /api/analytics/governance-status

Escalation Levels:
  RED: Critical supplier at high risk
       (OTIF<70% or Quality>5% AND
       single-source + high value)
  YELLOW: Supplier degrading
          (OTIF<85% or Quality>2%)
  GREEN: Healthy, no action needed

Governance Approval:
  Changes to resilience strategy
  require PM approval before execution

════════════════════════════════════════
ESCALATION FRAMEWORK
════════════════════════════════════════

RED Alert:
  → PM notified immediately
  → Action required within 1 hour
  → If unresolved >24 hours,
    escalate to executive

YELLOW Alert:
  → Logged for weekly review
  → Action plan required within 7 days

GREEN Status:
  → No action, continue monitoring
