── SECTION 1: IMPROVEMENT OPPORTUNITIES BY CATEGORY ─────────

  1a. QUICK WINS — implement this week (low effort, high impact)
  ----------------------------------------------------------

  QW1: Seasonal decomposition tuning (Period adjustment)
    Current: period=7 (weekly) for all SKUs
    Problem: Chemicals and Packaging have monthly cycles (period=30)
             that the weekly decomposition misses.
    Fix: Auto-detect period using ACF peak detection per SKU.
    Code: from statsmodels.tsa.stattools import acf
          acf_vals = acf(series, nlags=60)
          period = np.argmax(acf_vals[2:]) + 2
    Expected gain: −1.0 to −1.5 pts MAPE for Chemicals/Packaging

  QW2: Holiday calendar flag (India public holidays)
    Current: No holiday awareness in training features
    Fix: Add is_public_holiday binary feature using 'holidays' lib
    Code: pip install holidays
          import holidays
          india = holidays.India(years=[2023, 2024])
          df['is_public_holiday'] = df['date'].apply(
              lambda d: 1 if pd.Timestamp(d).date() in india else 0)
    Expected gain: −0.5 to −1.0 pts MAPE across all SKUs

  QW3: Momentum ratio feature (demand acceleration signal)
    Current: rolling_7 and rolling_28 treated independently
    Fix: Add ratio = rolling_7 / rolling_28 as explicit feature
    Code: df['demand_momentum'] = (
              df.groupby('sku_id')['quantity_demanded']
              .transform(lambda x: x.shift(1).rolling(7).mean()) /
              df.groupby('sku_id')['quantity_demanded']
              .transform(lambda x: x.shift(1).rolling(28).mean()))
    Expected gain: −0.5 to −1.0 pts MAPE (demand sensing signal)

  QW4: Fix SKU-00351 structural break (retrain from 2023-08-01)
    Current: Model trained on full history, underestimates by ~72%
    Fix: Add per-SKU training_start_date config dict
    Code: TRAINING_CUTOFFS = {'SKU-00351': '2023-08-01'}
          start = TRAINING_CUTOFFS.get(sku_id, '2023-01-01')
          train = sku_df[sku_df['date'] >= start]
    Expected gain: −8 to −10 pts MAPE for SKU-00351 alone

  QW5: Promo x day_of_week interaction term
    Current: is_promotion and day_of_week treated independently
    Fix: Add explicit interaction feature
    Code: df['promo_weekday'] = (
              df['is_promotion'] * (df['day_of_week'] < 5).astype(int))
          df['promo_weekend'] = (
              df['is_promotion'] * (df['is_weekend']))
    Expected gain: −1.0 to −2.0 pts MAPE for promo-driven SKUs
